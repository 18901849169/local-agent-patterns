# 提示词实验说明

本页记录复现实验的方法，不提供未经核验的分数或模型结论。

## 实验控制

固定模型、模型版本、temperature、任务和输出约束；同一条件重复运行，并保存原始输入输出。
对比时记录模型标签、Ollama 版本、日期和失败样例，避免仅保留成功结果。

## 对比维度

| 条件 | 输入方式 | 观察内容 |
| --- | --- | --- |
| Zero-shot | 任务与格式要求 | 格式遵循、答案是否可核验 |
| Few-shot | 同一任务加少量示例 | 是否遵循示例格式、是否依赖示例措辞 |
| Chain-of-Thought | 请求分步检查并给出答案 | 逻辑遗漏、结果一致性；解释不作为正确性的证据 |
| 纠错提示 | 提供包含错误前提的任务，要求指出问题 | 能否识别错误、是否编造信息或引用 |

可使用同一数学题、结构化字段提取题和“所有大语言模型都能联网获取最新信息吗”等错误前提题。
通过 `HelloAgentsLLM.think(messages=...)` 逐项发送任务，另行保存输出并核验。

发布仓库未包含原始实验结果文件，因此这些观察维度不能视为已获得的量化成果。
